# Shiori 生图扩展（shiori-extension-imagegen）

给 [Shiori](https://github.com/iownmmiku/Shiori) 用的扩展：在 QQ 群聊和私聊里，对方请角色画画、拍照、自拍或改图时，聊天模型可以调用画图工具。角色先按自己的性格和意愿决定画不画；文字回复照常先发，图片在后台画好后单独发出，一般要几十秒。

- 支持四种生图服务：OpenAI 兼容图像接口、Gemini 图像模型、NovelAI、本机或局域网的 ComfyUI
- 人格外貌：角色画自己时自动加上当前人格的外貌提示词，每张图里长得一样
- 参考图改图：对方在同一条消息里附了图片，可以照着改、换风格或照着画
- 每人每天限张数（默认 5 张），管理员不限；没画成的图退回次数
- 自带设置页：管理服务和密钥、人格外貌、测试生图

## 要求

- 支持「扩展」的 Shiori。扩展功能还没有正式发布，目前的 Shiori 正式版装不了这个扩展。
- 聊天模型支持工具调用，会话开启“允许使用工具”。
- 用参考图改图时，聊天模型要开启视觉能力，生图服务也要支持改图。
- 一个可用的生图服务和它的密钥（ComfyUI 不需要密钥）。

如果你的 Shiori 已经自带这个扩展（扩展页能看到「生图 · Shiori 自带」），就不用再装了。两份同名的扩展只会加载 Shiori 自带的那一份。

## 安装

1. 打开 Shiori 的数据目录（用 `--open-data` 参数启动 Shiori 可以直接打开它），进入里面的 `extensions` 文件夹，没有就新建一个。
2. 把本仓库放进去，文件夹名必须是 `imagegen`：

   ```bash
   git clone https://github.com/iownmmiku/shiori-extension-imagegen.git imagegen
   ```

   也可以在 GitHub 上下载 ZIP，解压后把文件夹改名为 `imagegen`，确认 `extension.json` 就在 `extensions/imagegen/` 下面。
3. 重启 Shiori，打开侧栏「拓展工具 → 扩展」，在「生图」卡片上点「启用」，确认可信。

扩展在 Shiori 进程里运行，权限和 Shiori 相同（可以读写 Shiori 的数据、联网）。请只从你信任的来源安装。

## 配置

在扩展页的「生图」卡片上：

- **打开「生图设置」**：添加生图服务、填写人格外貌、测试生图。
- **设置**：修改「每人每天最多张数」，0 表示只有管理员能用。

### 添加服务

在生图设置页点「添加 …」选择服务类型，填写接口地址、密钥和模型。第一个添加的服务会自动设为当前使用的服务，角色从这时起就能画图。

| 服务 | 接口地址 | 说明 |
|---|---|---|
| OpenAI 兼容图像接口 | 填到 `/v1` 为止，例如 `https://api.openai.com/v1` | 请求 `/images/generations`，改图请求 `/images/edits`。gpt-image、DALL·E 和多数中转站的绘图模型都走这个接口；DALL·E 3 和不少中转站不支持改图，请关闭「支持参考图改图」。接口返回图片链接时，只下载 5 MB 以内的公网图片。 |
| Gemini 图像模型 | 默认 `https://generativelanguage.googleapis.com/v1beta` | 请求 `/models/模型:generateContent`，比例用宽高比传给模型。没返回图片（例如被安全策略拦下）时按失败处理。 |
| NovelAI | `https://image.novelai.net` | 默认模型 `nai-diffusion-4-5-full`，可以调采样步数、引导值、采样器和改图强度。改图用 img2img，只取第一张参考图。 |
| ComfyUI | 例如 `http://127.0.0.1:8188` | 粘贴 ComfyUI「导出（API）」得到的工作流 JSON，把正面提示词等参数映射到节点输入，写成 `节点ID.inputs.输入名`（如 `6.inputs.text`）。只有正面提示词必填；映射了参考图（LoadImage 的 `image`）才支持改图。 |

每个服务可以填负面提示词。NovelAI 和 ComfyUI 有独立的负面字段；OpenAI 兼容接口和 Gemini 没有，默认不发送，打开「把负面提示词写进描述」后才会以 `Avoid: …` 附在描述后面。「等待上限」默认 180 秒，可设 5—600 秒。高级里的「附加请求参数」会合并进请求体，不能覆盖模型、提示词和参考图字段。

### 人格外貌

给每个人格写外貌提示词（发型、发色、瞳色、身材、常穿的衣服）和外貌负面提示词。角色画自己时会自动加上；画别的东西时不加。NovelAI 和 ComfyUI 建议用英文标签，外貌会放在描述最前面；OpenAI 兼容接口和 Gemini 用自然语言，外貌附在描述后面。

## 用法

在 QQ 里直接对角色说，例如「给我画一只猫」「发张自拍」「把这张图改成夜景」（同一条消息附上图片）。角色愿意画时会先回一句话，图片画好后单独发出；等待期间可以继续聊天，后来的消息不会取消正在画的图。

- 用完当天的次数后，角色会知道并告诉对方；次数按 Shiori「时间与日配额」里的时区每天零点重置。
- 没画成的图（服务出错、超时、文字没发出去）会退回次数，但服务商那边可能仍对失败的请求计费。
- 图没画出来时，聊天里只发一句简短原因（如「画得太久，超时了」）；完整原因（已遮掉密钥）在 Shiori「运行日志」的「生图」类别里，同时记录每张图是谁请求的、画面描述、用时和是否送达。
- 同一时间最多 6 张图在排队或正在画，一次只画一张。多人合并成一轮的群回复里不会画图。
- 本地网页聊天里没有画图工具，可以用设置页底部的「测试生图」试画（不占次数，服务商照常计费）。

## 数据

- 服务、人格外貌和每日计数保存在数据目录的 `extension_data/imagegen` 文件夹，密钥加密保存，页面不回显。
- 扩展的开关和「每人每天最多张数」保存在数据目录的 `extensions.json`。
- 普通应用备份不包含这些文件；生成的图片不在本机保留。

## 更新

在 `extensions/imagegen` 里执行 `git pull`（或重新下载替换文件夹），然后重启 Shiori。扩展的文件改动后，Shiori 会先把它停用，请在扩展页重新确认启用。

## 已知限制

- 用 QQ 官方机器人时，群里的被动回复有时间窗口（约 5 分钟），画得特别慢的图可能发不出去。
- 离线测试覆盖了四种服务的请求和响应格式；实际画面效果、是否遵守提示词取决于所选的模型和服务商。
